# 微信聊天记录图片导出整理 WeChat Chat Media Cleaner

一个面向 Windows 的单文件 GUI 工具，用来整理微信聊天记录相关的缓存媒体文件，支持 `.dat` 解密、图片视频筛选、缩略图清理和重复图片去重。

## 功能特性

- 解密微信 `.dat` 图片/视频缓存
- 支持同时汇总一个或两个来源文件夹
- 删除缩略图文件
- 按内容去重图片
- 删除图片、视频之外的其他文件
- 输出到新的结果目录，不修改原始数据
- 支持处理中安全停止，已完成结果会保留

## 运行环境

- Windows
- Python 3.7 及以上
- 无第三方依赖，仅使用 Python 标准库

## 启动方式

```bash
python wechat_chat_media_cleaner.py
```

## 使用说明

1. 启动程序。
2. 选择 `来源文件夹 A`。
3. 如有需要，再选择 `来源文件夹 B`。
4. 选择 `输出位置`。
5. 勾选需要的处理选项。
6. 点击 `开始处理`。
7. 在输出目录中查看结果。

## 可选处理项

- `启用 DAT 解密`
- `保留图片`
- `保留视频`
- `删除缩略图`
- `删除重复图片`
- `删除除图片视频外的其他文件`
- `完成后自动打开结果目录`

## 注意事项

- 原始目录不会被修改。
- 输出目录会自动创建带时间戳的新文件夹。
- 程序采用边处理边写出的方式，中途停止也会保留已完成结果。
- 开启 `删除重复图片` 后会执行内容级去重，处理速度会比直接复制略慢。

## 适用场景

- 从微信缓存 `.dat` 文件恢复图片
- 合并多个聊天记录缓存目录
- 清理缩略图和重复图片后归档
- 从混杂目录中筛出图片和视频
